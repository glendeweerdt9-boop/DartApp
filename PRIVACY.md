# DartApp Privacy Policy

Last updated: 21 September 2026

DartApp is a darts scoring application. This policy describes the current MVP build.

## Current data handling

The current build does not intentionally send game scores to a DartApp server. Scoring data shown in the app is handled locally by the application.

The login and Google-login screens currently serve as demo UI; they are not connected to a production identity provider or cloud database.

If a future release adds accounts, cloud synchronization, analytics, crash reporting, or other third-party services, this policy will be updated before that functionality is enabled.

## Third-party services

The source code is hosted on GitHub. The scoring features do not require a GitHub account.

## Contact

For privacy questions or data requests, use the contact address published on the app's store listing.
