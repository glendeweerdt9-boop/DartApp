## Short description

## Full description
DartApp is a modern dark-themed darts scoring app for casual games and practice.

Features include:
- 501, 301 and 701
- Cricket
- Bob's 27
- Half-It
- 1–8 players
- Automatic scoring and bust detection
- Checkout suggestions for x01
- Undo
- Match history
- Player statistics
- DartBot practice mode
- Voice caller settings in the app interface

The current release focuses on the core scoring experience. Account login, cloud synchronization and production voice services are not yet enabled.
