# DartApp 🎯

Cross-platform darts app voor iPhone en Android, gebouwd met Flutter.

## MVP
- Login / registratie UI
- Dashboard
- 501, 301, 701
- Cricket, Bob's 27, Half-It
- 1–8 spelers
- x01 score-invoer en bust-detectie
- Undo
- Basis statistieken per wedstrijd

## Starten
flutter pub get
flutter run

## Roadmap
Firebase Authentication, Google login, Firestore, dartboard input, checkout suggestions, legs/sets, DartBot 1–10, Nederlandse/Engelse caller en Bluetooth audio.
